# Owner flows

## Edit public content

Sign in → Overzicht → Website aanpassen → choose page/section → edit labelled fields → save concept → preview → confirm publish → server authorization → persist published revision → update public projection → audit event.

## Edit a trajectory

Sign in → Trajecten → select item → edit verified content → save concept → preview → publish. Commercial fields remain gated until authoritative values are supplied.

## Manage an intake request

Sign in → Aanvragen → select record → review minimum necessary personal data → update allowed follow-up state → audit event. Export is not enabled by default.
