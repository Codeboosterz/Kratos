# Component contract

CMS shell components: owner sidebar, mobile menu drawer, owner topbar, task card, status card, empty state, error/retry banner, field group, section accordion, media picker, preview frame, sticky save bar, and publish confirmation.

Every mutation control shows loading, persisted success, normalized failure, retry where safe, and a disabled reason. `Publiceren` is never enabled until authentication, persistence, authorization, and audit logging are active.
