# Kratos design system

The current public website is the approved visual source of truth for marketing and CMS surfaces.

## Tokens

- Carbon: `#080A08`
- Charcoal: `#121510`
- Soft charcoal: `#1A1D18`
- Off-white: `#F4F6EF`
- Muted: `#A8A99F`
- Lime: `#A9CF68`
- Bright lime: `#B9EA68`
- Error accent: `#F06A22`, only for real errors
- Border: `rgba(244, 246, 239, 0.14)`

Public display type is Barlow Condensed, italic uppercase where appropriate. CMS interface type is Inter; display type is limited to major headings. One lime primary action per task area. Controls are at least 44px high, have persistent labels, and show visible focus.

Stitch source: project `246290204144160391`, design system `3889512355704354260`.
