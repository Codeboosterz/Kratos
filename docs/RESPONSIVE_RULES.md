# Responsive rules

- Desktop: persistent 240px owner sidebar and calm two-column overview.
- Below 900px: sidebar becomes a labelled menu drawer; content becomes one column.
- Mobile: 20px gutters, 44px minimum targets, no icon-only critical actions, no page-level horizontal overflow.
- Editors stack fields above preview; sticky actions become a bottom action group that does not cover content.
- Tables scroll inside labelled regions with the first meaningful column preserved where practical.
- Dialogs and bottom sheets fit the viewport and allow internal scrolling.
